Aviso de privacidad del pre-registro

Importante: Este formulario recoge datos de contacto para gestionar el interés en la beta de MotoYa. No es una solicitud de empleo, contrato ni garantía de participación. No introduzcas cédula, documentos, claves, datos bancarios ni información sensible.

1. Responsable y alcance

MotoYa es un proyecto en desarrollo. Este aviso describe el tratamiento de los datos enviados mediante el formulario público de pre-registro de este sitio web.

2. Datos que se recogen

El formulario puede recoger el tipo de participación elegido (socio conductor, usuario o comercio), nombre, teléfono, zona o ciudad, correo electrónico opcional y un mensaje opcional. También se registra automáticamente la fecha y hora de envío en la base de datos.

3. Para qué se utilizan

Los datos se utilizan para gestionar el pre-registro, conocer el interés en MotoYa, organizar la posible convocatoria de beta y contactar a la persona sobre el proyecto. Enviar el formulario no garantiza una invitación ni la incorporación a MotoYa.

4. Almacenamiento y proveedores

Los datos enviados se almacenan en una base de datos de Supabase asociada al proyecto MotoYa. El sitio público está alojado mediante GitHub Pages. Estos proveedores procesan información técnica necesaria para prestar sus servicios. El acceso al contenido de los pre-registros desde la web pública está bloqueado mediante políticas de seguridad de la base de datos; el equipo autorizado puede consultarlos desde el panel privado.

5. Compartición y publicación

Los datos del pre-registro no se muestran públicamente en el sitio ni en el foro. No deben compartirse con comercios, conductores ni otros usuarios para fines ajenos a la gestión del proyecto sin informar previamente a la persona y contar con la base legal correspondiente.

6. Conservación y solicitudes

El proyecto todavía debe definir y publicar un plazo formal de conservación, así como un canal de contacto para solicitudes de acceso, corrección o eliminación. Mientras esos procedimientos se formalizan, evita enviar información que no sea estrictamente necesaria. Antes de abrir una convocatoria amplia, MotoYa debe completar estos datos y revisar este aviso para los requisitos legales aplicables.

7. Seguridad y límites

MotoYa aplica controles técnicos para limitar el acceso público a los registros, pero ningún servicio en internet puede prometer seguridad absoluta. La protección antispam del formulario está en una fase básica y todavía requiere medidas adicionales antes de una promoción masiva.
